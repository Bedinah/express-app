## Day 1 – Database Setup Complete

### Problem Solved
Replaced the hardcoded `fruits` array in routes/fruits.js with real databases.
Data now persists across server restarts.

### PostgreSQL + Sequelize
- Database: fruitsdb
- Model: Fruit (name, color)
- Routes: GET /, GET /:id, POST /, PUT /:id, DELETE /:id

### MongoDB + Mongoose
- Database: fruitsdb
- Model: Fruit (name, color)
- Routes: GET /, GET /:id, POST /, PUT /:id, DELETE /:id  (prefix: /fruits-mongo)

### Key Difference Noted
Sequelize uses integer `id` (auto-increment).
Mongoose uses string `_id` (auto-generated by MongoDB).
Route logic is nearly identical — only the data layer changed.
